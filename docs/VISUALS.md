# Иллюстрации документации

[Документация](README.md) / Поддержка иллюстраций

В руководствах встречаются снимки работающего приложения и SVG-заглушки. Заглушки в `docs/assets/screenshots/` явно подписаны как места для будущих кадров; они не подтверждают реализацию показанной функции. Снимки в `docs/image/NT/` и `docs/image/NT_RUN/` относятся к конкретным историческим прогонам.

## Какие кадры нужны

| Состояние | Что должно читаться |
| :--- | :--- |
| Рабочее пространство | Выбранный сценарий, входные материалы, граф, область запроса и состояние |
| Входные материалы | Папка и явно выбранные файлы; для `update` — основной документ и новые материалы |
| Выполнение | Активный узел, журнал событий, документ этапа |
| Подтверждение | Название действия, его содержимое и назначение, доступные решения |
| Результат | Документ и фактический статус публикации или созданные ключи Jira |
| Настройки | Названия параметров, замаскированные секреты, состояние сохранения |
| Проведение НТ | План и скрипт до запуска, текущий `test_id`, метрики и отдельный исторический вердикт |

## Как обновлять

1. Воспроизведите нужное состояние на тестовых материалах. Для НТ используйте [инструкцию nt-testbed](NT_RUN_TESTBED.md#автоматически-со-снимками-интерфейса): скрипт съёмки выполняет реальный тест и подтверждает действия автоматически.
2. Снимите читаемый кадр нужной области без токенов и личных данных. Не добавляйте в изображение вымышленные результаты.
3. Сохраните изображение рядом с материалами соответствующего руководства, замените Markdown-ссылку и подпись заглушки.
4. Укажите, к какому сценарию или прогону относится снимок. Не смешивайте цифры нового отчёта со старыми кадрами; исторический пример помечайте явно.
5. Проверьте ссылку, подпись и читаемость изображения в отрендеренной странице.

Схемы Mermaid храните рядом с поясняющим текстом. Для схемы развёртывания обозначайте процессы, сетевые границы и каталоги хранения; граф НТ должен показывать отдельные backend, runner, worker/k6 и цель нагрузки.
