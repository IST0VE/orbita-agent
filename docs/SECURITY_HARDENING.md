# Усиление защиты, 7 сентября 2026

Исходный аудит не доказывал абсолютную безопасность. При повторной проверке найдены и исправлены конкретные границы доверия:

- Необязательная авторизация только `/api/*` заменена обязательной глобальной проверкой Bearer. Проверены реальные встроенные маршруты LangGraph, включая `/noauth/threads`: анонимный запрос получает 401. Без настроенного токена сервер возвращает 503.
- Лимит тела и времени чтения применяется до обработчика ко всему HTTP API, включая chunked-запросы. Ответы не кешируются; WebSocket закрыт.
- Все frontend-запросы, включая SDK, используют общий авторизованный транспорт. Удалённый HTTP и перенаправления запрещены.
- Запись произвольных переменных окружения из UI запрещена. Токен и пароль Compose меняются только на сервере. Неизвестные поля маскируются, `${...}` при записи запрещён, временный файл создаётся через `mkstemp` (0600 на POSIX).
- Jira/Confluence не следуют HTTP-перенаправлениям, в том числе с телом документа. Переопределения адреса LLM проверяются на HTTPS и отсутствие встроенных credentials/query/fragment; loopback HTTP разрешён.
- Инструменты материалов отказывают в чтении `.env*`, `*.env`, `*.pem`, `*.key`. Шаблоны исключения Git и Docker расширены.
- Удалён стандартный пароль PostgreSQL из Compose: требуется отдельный `POSTGRES_PASSWORD`.
- Запрет реальной сети обнаружил три ранее незамоканных сценария тестов: список проектов Jira и публикацию Confluence. Заглушки исправлены; защита сети остаётся включённой.
- В Ruff включены проверки опасного исполнения кода, десериализации, shell и отключения TLS.

Глобальное подключение middleware соответствует [механизму LangGraph](https://langchain-ai.github.io/langgraph/how-tos/http/custom_middleware/) и дополнительно проверено на установленном сервере тестом `test_server_security_integration.py` без запуска фоновых работников и внешних сервисов.

Проверка истории: 38 коммитов, совпадений распространённых сигнатур ключей нет, коммитов с `.env` нет. Это поиск по ограниченному набору сигнатур, а не доказательство отсутствия любого секрета или намеренной закладки.

Локальная проверка Python: 792 теста прошли, один POSIX-тест прав пропущен на Windows. После заключительных изменений настроек повторно прошли 66 целевых тестов. Frontend: 21 тест и production-сборка прошли. Ruff и `git diff --check` прошли. Проверены синтаксис Compose и обязательные реквизиты без запуска контейнеров.

Актуальный аудит зависимостей не завершён: сетевой sandbox блокирует реестры, автоматическая проверка разрешений отклонила отправку имён и версий установленных Python-пакетов в PyPI без отдельного согласия пользователя. Зависимости нельзя считать проверенными на отсутствие известных уязвимостей по результатам этой работы.

Остаются эксплуатационные требования: TLS при удалённом доступе, ограничения частоты и ресурсов, индивидуальная авторизация для нескольких пользователей, корректные ACL и подготовка входных документов без секретов. Общий токен даёт административный доступ ко всем данным. Содержимое разрешённых документов передаётся выбранной модели; произвольные секреты в тексте автоматически исключить нельзя. Инструкция настройки — в [SECURITY.md](../SECURITY.md).
