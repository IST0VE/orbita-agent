## Словарь

| Термин | Простое объяснение |
| :--- | :--- |
| Сценарий / граф | Последовательность обработки: например, аналитика или сверка пакета |
| Этап / узел | Один шаг: прочитать источник, написать документ, запросить подтверждение |
| Тред | Сохранённый контекст работы. В одном треде может быть несколько запусков |
| Прогон / run | Одно выполнение графа по отправленному запросу |
| Артефакт | Документ этапа; он ещё не обязательно сохранён в файл |
| Публикация | Запись результата в выбранное место: файлы или Confluence |
| Interrupt | Пауза графа, ожидающая решения пользователя |
| Чекпоинт | Сохранённое состояние выполнения, которое использует LangGraph |
| Манифест UI | Описание полей, виджетов и действий сценария для интерфейса |
