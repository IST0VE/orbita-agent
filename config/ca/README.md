# Корневые сертификаты компании

Нужны серверному режиму ([`docker-compose.server.yml`](../../docker-compose.server.yml)). Keycloak доверяет сертификатам из этой папки, когда подключается к контроллеру домена по `ldaps://`. Публичные центры сертификации он знает и без них. Если сертификат контроллера домена выпущен внутренним центром компании, без этой папки проверка подключения в консоли ответит `SSLHandshakeFailed`.

Положите сюда корневой сертификат компании и промежуточные, если они есть. Формат — PEM, расширение `.pem` или `.crt`, по одному сертификату на файл или цепочкой в одном файле. Остальные файлы, включая этот README, Keycloak пропускает.

Папка монтируется в `/opt/keycloak/conf/truststores` только на чтение; её содержимое в `.gitignore`. После добавления сертификата выполните `docker compose restart keycloak`. В журнале (`docker compose logs keycloak`) появится строка `Found the following truststore files` со списком прочитанных файлов.

Агент эту папку пока не читает. Доверие к внутренним сертификатам Jira, Confluence и шлюза модели не настроено.
