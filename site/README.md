# Orbita landing

Standalone static sales landing for the System Analysis CI positioning.

No backend and no build step are required.

## Preview locally

From the repository root:

    cd site
    python3 -m http.server 4173

Then open http://localhost:4173.

## Deploy

The `site` folder can be deployed as-is to Vercel, Netlify, Cloudflare Pages or GitHub Pages.

## Current CTA

The pilot CTA intentionally opens a GitHub issue in this repository. Replace it with a CRM/form link when a sales inbox or form endpoint exists.

## Positioning

Primary promise: Catch requirement, API and architecture inconsistencies before merge.

The page intentionally sells the engineering outcome rather than LangGraph, agents, RAG or model choice.
