# Установка для разработки: редактируемые пакеты репозитория и dev-набор.
#
# Диапазоны версий описывает pyproject.toml. Приложению этого мало: диапазон
# разрешается по-разному сегодня и через месяц, и уязвимая транзитивная версия
# приезжает молча. Поэтому рядом лежит requirements.lock — зафиксированный
# набор runtime-зависимостей для разработки, CI и Docker.
# Обновляется он явно: scripts/write_lock.py. Dev-инструменты не входят в lock.
#
# Порядок важен: costmeter — отдельный пакет и ещё не опубликован на PyPI,
# поэтому он ставится из папки раньше, чем агент объявит его зависимостью.
-c requirements.lock
-e ./packages/costmeter
-e .[dev]
